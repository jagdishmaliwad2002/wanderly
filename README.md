# Wanderly — Travel Booking Website

A modern, responsive travel booking landing page built with pure HTML, CSS, and vanilla JavaScript.

**Created by Jagdish**

---

## 📌 Overview

Wanderly is a clean and modern travel booking website template. It helps users discover destinations, search for trips, compare travel options, and book experiences — all from a single, beautifully designed page.

This project is perfect as a starting point for:
- Travel agencies
- Booking platforms
- Personal travel blogs
- Portfolio projects

---

## ✨ Features

- **Modern Hero Section** — Eye-catching headline, CTA buttons, and floating info cards
- **Trip Search Bar** — Destination, check-in, check-out, and traveler selection
- **Animated Statistics** — Count-up numbers for destinations, partners, bookings, and ratings
- **Trending Destinations** — Beautiful image cards with pricing and tags
- **Why Choose Us** — Feature grid with icons and hover effects
- **How It Works** — Simple 3-step booking process
- **Traveler Testimonials** — Social proof with avatars and star ratings
- **Newsletter CTA** — Email subscription section with toast notification
- **Fully Responsive** — Works smoothly on mobile, tablet, and desktop
- **Scroll Animations** — Smooth reveal effects using Intersection Observer
- **Mobile Navigation** — Hamburger menu with animated toggle
- **Glassmorphism Effects** — Modern translucent UI elements
- **No Dependencies** — Pure HTML, CSS, and JavaScript (no frameworks)
